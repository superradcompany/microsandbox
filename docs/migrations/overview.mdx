A local sandbox's saved state includes its root filesystem, additional disks, snapshots, configuration, and the metadata that connects them. Upgrades can change these formats or their directory layout, so existing sandboxes may need migration.

Some changes migrate automatically; others need diagnosis or repair before the sandbox can start. Choose the guide for the upgrade affecting your sandboxes.
