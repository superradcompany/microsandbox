Headless Chromium does not require GPU acceleration. This recipe uses Microsoft's Playwright image to capture a screenshot and optionally run a persistent browser server for a host-side test runner or agent.

<Note>
  The Playwright image is large. Its first pull can take several minutes, while cached browser launches are much faster. Consider turning a prepared browser sandbox into a [snapshot](/recipes/sandboxing/warm-workers) for repeated jobs.
</Note>

## Capture a screenshot

```sh
msb run --name playwright-shot --replace \
  --cpus 2 --memory 2G --root-disk 4G \
  mcr.microsoft.com/playwright:v1.61.0-noble -- sh -lc '
    npx -y playwright@1.61.0 screenshot \
      --browser chromium \
      https://example.com \
      /root/example.png &&
    stat -c "%s bytes" /root/example.png
  '
```

Copy the artifact out of the stopped sandbox:

```sh
msb cp playwright-shot:/root/example.png ./example.png
```

The smoke test used for this recipe produced a valid 15,909-byte PNG. Rendering can vary slightly between releases and hosts, so verify the file rather than asserting an exact byte count.

## Run a remote Playwright server

```sh
msb run -d --name playwright-server --replace \
  --cpus 2 --memory 2G --root-disk 4G \
  -p 127.0.0.1:3000:3000 \
  mcr.microsoft.com/playwright:v1.61.0-noble -- sh -lc '
    exec npx -y playwright@1.61.0 run-server \
      --host 0.0.0.0 \
      --port 3000
  '
```

Verify the forwarding path:

```sh
curl http://127.0.0.1:3000/
```

The server returns `Running` and logs its WebSocket endpoint:

```sh
msb logs playwright-server
```

Connect a matching Playwright client to `ws://127.0.0.1:3000/`. Keep the client and server versions aligned.

<Warning>
  The remote server has no application-level authentication. This recipe binds the host side to loopback intentionally. Do not publish it on `0.0.0.0` or an internet-facing interface without an authenticated proxy.
</Warning>

## Cleanup

```sh
msb rm -f playwright-shot playwright-server
rm ./example.png
```

The final `rm` deletes the copied screenshot from the host; omit it if you want to keep the artifact.
