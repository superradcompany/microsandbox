title: VNC desktop
description: Open a CPU-only Linux desktop in the browser with TigerVNC and noVNC

VNC does not require a physical display or GPU. TigerVNC's X server draws into a virtual framebuffer in guest memory, encodes changed regions, and sends them to the client. noVNC provides the browser client over WebSockets.

This recipe installs a minimal Openbox desktop rather than a full XFCE environment. It is useful for GUI-only utilities, observing browser sessions, and testing desktop applications—not for graphics-performance workloads.

## Start the desktop

```sh
msb run -d --name vnc-desktop --replace \
  --cpus 2 --memory 2G --root-disk 5G \
  -p 127.0.0.1:6080:6080 \
  --script start-desktop='set -eu
    apt-get update
    DEBIAN_FRONTEND=noninteractive apt-get install -y --no-install-recommends \
      ca-certificates novnc openbox tigervnc-standalone-server websockify xterm
    rm -rf /var/lib/apt/lists/*
    Xtigervnc :1 -SecurityTypes None -geometry 1280x800 -depth 24 >/tmp/xvnc.log 2>&1 &
    vnc_pid=$!
    sleep 2
    kill -0 "$vnc_pid"
    DISPLAY=:1 openbox >/tmp/openbox.log 2>&1 &
    DISPLAY=:1 xterm -geometry 100x30+40+40 >/tmp/xterm.log 2>&1 &
    exec websockify --web=/usr/share/novnc 0.0.0.0:6080 localhost:5901' \
  --entrypoint start-desktop \
  debian:bookworm-slim
```

Detached mode returns as soon as the VM starts, before the desktop packages are ready. The first install downloads approximately 128 MB, uses roughly 560 MB of guest disk, and can take a few minutes. Wait for noVNC to respond:

```sh
until curl -fsS http://127.0.0.1:6080/vnc.html >/dev/null; do
  echo "Waiting for noVNC..."
  sleep 5
done
```

Open [http://127.0.0.1:6080/vnc.html?autoconnect=1&resize=scale](http://127.0.0.1:6080/vnc.html?autoconnect=1&resize=scale). You should see an Openbox desktop with an xterm window.

## Verify the services

```sh
curl -sS http://127.0.0.1:6080/vnc.html | head
msb exec vnc-desktop -- sh -lc 'grep -E "Listening|created VNC server" /tmp/xvnc.log'
```

<Warning>
  VNC authentication is disabled inside this VM. The host listener is therefore intentionally restricted to `127.0.0.1`. Do not publish port 6080 on a LAN or public interface without VNC authentication, TLS, and an authenticated reverse proxy.
</Warning>

## Cleanup

```sh
msb rm -f vnc-desktop
```

For repeated launches, stop the prepared sandbox, create a snapshot, and boot desktops from that snapshot instead of reinstalling the packages.
