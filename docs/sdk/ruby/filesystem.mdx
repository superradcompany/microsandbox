## Sandbox

#### <span className="msb-recv">sandbox.</span><span className="msb-hn">fs</span>

```ruby
sandbox.fs # => Microsandbox::Filesystem
```

Get the filesystem helper for this sandbox.

## Filesystem

These helpers also have direct sandbox equivalents: `sandbox.fs_read`, `fs_write`, `fs_mkdir`, `fs_list`, `fs_stat`, `fs_exists?`, `fs_copy`, `fs_rename`, `fs_remove`, `fs_remove_dir`, `fs_copy_from_host`, and `fs_copy_to_host`, with the same arguments and return values.

## Metadata

Hashes use string keys. Optional timestamps are omitted when unavailable. Ruby does not expose streaming filesystem handles.

<p className="msb-label">Fields</p>

<div className="msb-params">
  <div className="msb-param">
    <div className="msb-param-key"><code>&quot;path&quot;</code><span className="msb-type">String</span></div>
    <div className="msb-param-desc">Entry path; returned by list</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>&quot;kind&quot;</code><span className="msb-type">String</span></div>
    <div className="msb-param-desc">file, directory, symlink, or other</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>&quot;size&quot;</code><span className="msb-type">Integer</span></div>
    <div className="msb-param-desc">Size in bytes</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>&quot;mode&quot;</code><span className="msb-type">Integer</span></div>
    <div className="msb-param-desc">File mode</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>&quot;uid&quot;, &quot;gid&quot;</code><span className="msb-type">Integer</span></div>
    <div className="msb-param-desc">Owner and group IDs</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>&quot;modified&quot;, &quot;accessed&quot;</code><span className="msb-type">String</span></div>
    <div className="msb-param-desc">RFC 3339 timestamps, when available</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>&quot;readonly&quot;</code><span className="msb-type">Boolean</span></div>
    <div className="msb-param-desc">Returned by stat</div>
  </div>
  <div className="msb-param">
    <div className="msb-param-key"><code>&quot;created&quot;</code><span className="msb-type">String</span></div>
    <div className="msb-param-desc">Creation timestamp, when available from stat</div>
  </div>
</div>
