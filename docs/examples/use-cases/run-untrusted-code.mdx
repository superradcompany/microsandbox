Run each submission in a fresh microVM instead of the host process. This example copies one Python file into an isolated worker, disables its network, applies resource limits, and returns the program's output.

## Create a submission

Save this as `submission.py`:

```python submission.py
import socket

print("answer:", sum(range(10)))

try:
    socket.create_connection(("example.com", 443), timeout=1)
except OSError:
    print("network: blocked")
```

## Run it

<Tooltip tip="This example works on microsandbox cloud after omitting replace-on-create from the command."><span className="msb-badge-limited">Limited on cloud <Icon icon="circle-info" size={11} /></span></Tooltip>

```sh
msb run --name untrusted-python --replace \
  --cpus 1 --memory 256M --max-duration 30s \
  --no-net --security restricted \
  --rlimit nproc=64 --rlimit nofile=128 --rlimit fsize=10485760 \
  --copy-file ./submission.py:/workspace/submission.py \
  --workdir /workspace \
  python:3.13-slim -- python -I submission.py
```

The command prints:

```text
answer: 45
network: blocked
```

The sandbox stops when the program exits. Its filesystem remains available for logs or output inspection until cleanup.

## What this isolates

- **Fresh microVM.** The submission gets its own kernel and filesystem instead of running in the host process.
- **No network.** `--no-net` removes guest network access.
- **Bounded resources.** CPU, memory, lifetime, process count, open files, and file size are capped.
- **Restricted profile.** The guest process cannot elevate with setuid binaries or administer guest mounts.
- **Narrow input.** Only `submission.py` is copied into the guest.

<Warning>
  File-size limits do not cap stdout or stderr. A public execution service should also limit concurrent sandboxes and bound streamed output before retaining or returning it.
</Warning>

## Cleanup

```sh
msb rm -f untrusted-python
```

To build this flow into an application, use the same create, copy, execute, and remove lifecycle from the [SDK for your language](/sdk/overview).
