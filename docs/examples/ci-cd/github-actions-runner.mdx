<Tooltip tip="This workflow creates and restores local disk snapshots, which are not available on microsandbox cloud."><span className="msb-badge-local">Local-only <Icon icon="circle-info" size={11} /></span></Tooltip>

The included controller registers a fresh runner for one repository job, then removes the runner and VM.

This runner supports shell steps and JavaScript actions such as `actions/checkout` and `actions/upload-artifact`. For a simpler checkout-and-test workflow, see [PR checks](/examples/ci-cd/pr-checks).

## Prepare the host

Install `msb` and the GitHub CLI on a Linux host with KVM or an Apple Silicon Mac. A hosted Linux machine must expose nested virtualization and make `/dev/kvm` available to the account running `msb`.

```sh
case "$(uname -s)" in
  Linux) test -r /dev/kvm -a -w /dev/kvm ;;
  Darwin) test "$(uname -m)" = arm64 ;;
  *) exit 1 ;;
esac
msb doctor
gh auth status --hostname github.com
```

Authenticate `gh` with a fine-grained token limited to the target repository, with **Administration: write**, and valid for at least two hours. The controller keeps this host token out of the VM.

Choose the repository and a custom label. Keep these values in the same terminal for the rest of the walkthrough:

```sh
repo=acme/widget
label=msb-jit-acme-widget-7d6e
```

Use a unique label so only this temporary runner claims the job.

## Build the runner snapshot

Save the builder as `/usr/local/sbin/build-msb-github-runner`. It installs and verifies the matching GitHub runner once, then creates an integrity-checked snapshot for later jobs.

<Accordion title="Snapshot builder source">

```bash /usr/local/sbin/build-msb-github-runner
#!/usr/bin/env bash
set -euo pipefail

runner_version=2.336.0

case "$(uname -m)" in
  x86_64)
    runner_arch=x64
    runner_sha256=04cf0be1aff4c3ec3554466c39124ca250e3effd8873bb7e8d68535aa9505d5d
    ;;
  aarch64 | arm64)
    runner_arch=arm64
    runner_sha256=58b758e420b87093fbd4bfddd368074960053e2f1388f01848c82624b90f27d1
    ;;
  *)
    echo "unsupported host architecture: $(uname -m)" >&2
    exit 2
    ;;
esac

snapshot_name="github-actions-runner-${runner_version}-${runner_arch}"
build_key="$(date -u +%Y%m%dT%H%M%SZ)-$$-${RANDOM}"
builder_name="ghr-build-${runner_arch}-${build_key}"

cleanup() {
  msb rm -f "$builder_name" >/dev/null 2>&1 || true
}
trap cleanup EXIT

msb doctor

msb run --name "$builder_name" \
  --cpus 2 --memory 4G --root-disk 16G \
  --max-duration 20m \
  --net public \
  --security default \
  --env "RUNNER_VERSION=$runner_version" \
  --env "RUNNER_ARCH=$runner_arch" \
  --env "RUNNER_SHA256=$runner_sha256" \
  ubuntu:24.04 -- bash -lc '
    set -euo pipefail
    export DEBIAN_FRONTEND=noninteractive

    apt-get update
    apt-get install -y --no-install-recommends \
      ca-certificates curl git git-lfs jq sudo

    archive=/tmp/actions-runner.tar.gz
    curl --fail --location --silent --show-error \
      --retry 5 --retry-delay 2 --retry-all-errors \
      --output "$archive" \
      "https://github.com/actions/runner/releases/download/v${RUNNER_VERSION}/actions-runner-linux-${RUNNER_ARCH}-${RUNNER_VERSION}.tar.gz"
    printf "%s  %s\n" "$RUNNER_SHA256" "$archive" | sha256sum --check --strict -

    install -d -m 0755 /opt/actions-runner
    tar -xzf "$archive" -C /opt/actions-runner
    /opt/actions-runner/bin/installdependencies.sh

    useradd --create-home --shell /bin/bash runner
    printf "runner ALL=(ALL:ALL) NOPASSWD: ALL\n" > /etc/sudoers.d/runner
    chmod 0440 /etc/sudoers.d/runner
    visudo --check --file=/etc/sudoers.d/runner
    chown -R runner:runner /opt/actions-runner

    su - runner -c "test -x /opt/actions-runner/run.sh && sudo -n true"
    test "$(su - runner -c "/opt/actions-runner/bin/Runner.Listener --version")" = "$RUNNER_VERSION"

    rm -f "$archive"
    apt-get clean
    rm -rf /var/lib/apt/lists/*
  '

msb snapshot create "$snapshot_name" \
  --from "$builder_name" \
  --integrity \
  --force

msb snapshot verify "$snapshot_name"
printf 'Prepared %s\n' "$snapshot_name"
```

</Accordion>

Run the builder once on each native architecture you operate:

```sh
sudo chown root /usr/local/sbin/build-msb-github-runner
sudo chmod 0755 /usr/local/sbin/build-msb-github-runner
/usr/local/sbin/build-msb-github-runner
```

The snapshot contains the runner and its tools, but no repository checkout or credentials. Jobs run as the unprivileged `runner` user with `sudo` available only inside the VM.

## Add a narrowly scoped workflow

Add this workflow to the repository's default branch. GitHub only accepts `workflow_dispatch` when the workflow file exists there.

```yaml .github/workflows/microsandbox-jit.yml
name: Microsandbox JIT runner

on:
  workflow_dispatch:
    inputs:
      runner_label:
        description: Unique label for the temporary runner
        required: true
        type: string

permissions:
  contents: read

jobs:
  verify:
    runs-on: ${{ inputs.runner_label }}
    timeout-minutes: 45
    steps:
      - uses: actions/checkout@v4
        with:
          persist-credentials: false

      - name: Verify isolation and runner tools
        shell: bash
        run: |
          set -euo pipefail
          test "$(id -u)" -ne 0
          test ! -S /var/run/docker.sock
          sudo -n true
          test -f README.md
          printf 'runner=%s\nsha=%s\n' "$RUNNER_NAME" "$GITHUB_SHA" > runner-proof.txt

      - uses: actions/upload-artifact@v4
        with:
          name: runner-proof
          path: runner-proof.txt
          retention-days: 1
```

The workflow grants only read access and prevents checkout from leaving its token in Git configuration.

## Install the JIT controller

Save the controller as `/usr/local/sbin/msb-github-jit`, owned by the host administrator and outside repository checkouts. It creates one JIT runner and one VM per invocation.

<Accordion title="Hardened JIT controller source">

```bash /usr/local/sbin/msb-github-jit
#!/usr/bin/env bash
set -euo pipefail

usage() {
  echo "usage: msb-github-jit OWNER/REPO RUNNER_LABEL" >&2
  exit 2
}

repo="${1:-}"
runner_label="${2:-}"
[[ $# -eq 2 ]] || usage

if [[ ! "$repo" =~ ^[A-Za-z0-9][A-Za-z0-9-]{0,38}/[A-Za-z0-9._-]{1,100}$ ]]; then
  echo "repository must be OWNER/REPO using GitHub-safe characters" >&2
  exit 2
fi

owner="${repo%%/*}"
repository="${repo#*/}"
if [[ "$owner" == *- || "$repository" == "." || "$repository" == ".." ]]; then
  echo "repository owner or name is invalid" >&2
  exit 2
fi

if (( ${#runner_label} > 64 )) || [[ ! "$runner_label" =~ ^[A-Za-z0-9][A-Za-z0-9._-]*$ ]]; then
  echo "runner label must be 1-64 letters, numbers, dots, underscores, or hyphens" >&2
  exit 2
fi

normalized_label="$(printf '%s' "$runner_label" | tr '[:upper:]' '[:lower:]')"
case "$normalized_label" in
  self-hosted | linux | windows | macos | x64 | arm64 | arm)
    echo "runner label must be a unique custom label, not $runner_label" >&2
    exit 2
    ;;
esac

for required_command in gh msb; do
  if ! command -v "$required_command" >/dev/null 2>&1; then
    echo "required command not found: $required_command" >&2
    exit 2
  fi
done

case "$(uname -s)" in
  Linux)
    if [[ ! -r /dev/kvm || ! -w /dev/kvm ]]; then
      echo "/dev/kvm must be readable and writable" >&2
      exit 2
    fi
    ;;
  Darwin)
    if [[ "$(uname -m)" != arm64 ]]; then
      echo "local macOS validation requires Apple Silicon" >&2
      exit 2
    fi
    ;;
  *)
    echo "unsupported host: $(uname -s)" >&2
    exit 2
    ;;
esac

case "$(uname -m)" in
  x86_64) runner_arch=x64 ;;
  aarch64 | arm64) runner_arch=arm64 ;;
  *) echo "unsupported host architecture: $(uname -m)" >&2; exit 2 ;;
esac

runner_version=2.336.0
snapshot_name="github-actions-runner-${runner_version}-${runner_arch}"
api_version=2026-03-10
github_token_command="${MSB_GITHUB_TOKEN_COMMAND:-}"

if [[ -n "$github_token_command" && ( "$github_token_command" != /* || ! -f "$github_token_command" || ! -x "$github_token_command" ) ]]; then
  echo "MSB_GITHUB_TOKEN_COMMAND must be an absolute path to an executable" >&2
  exit 2
fi

artifact_root="${MSB_GITHUB_STATE_DIR:-${RUNNER_TEMP:-${TMPDIR:-/tmp}}}"
if [[ ! -d "$artifact_root" || ! -w "$artifact_root" ]]; then
  echo "artifact root must be an existing writable directory: $artifact_root" >&2
  exit 2
fi

umask 077
artifact_dir="$(mktemp -d "${artifact_root%/}/msb-github-jit.XXXXXXXX")"
chmod 0700 "$artifact_dir"
runner_id_file="$artifact_dir/runner-id"

nonce="${artifact_dir##*.}"
started_at="$(date -u +%Y%m%dT%H%M%SZ)"
runner_name="msb-${owner:0:12}-${repository:0:12}-${started_at}-${nonce}"
sandbox_name="ghr-${started_at}-${nonce}"
sandbox_may_exist=0
jit_runner_may_exist=0

printf '%s\n' "$repo" > "$artifact_dir/repository"
printf '%s\n' "$runner_name" > "$artifact_dir/runner-name"
printf '%s\n' "$sandbox_name" > "$artifact_dir/sandbox-name"

github_api() {
  local api_token
  local api_status=0

  if [[ -n "$github_token_command" ]]; then
    if ! api_token="$("$github_token_command" "$repo")"; then
      echo "failed to mint a GitHub App installation token" >&2
      return 1
    fi
    if [[ -z "$api_token" || "$api_token" =~ [[:space:]] ]]; then
      echo "MSB_GITHUB_TOKEN_COMMAND returned an invalid token" >&2
      return 1
    fi

    GH_TOKEN="$api_token" env -u GH_DEBUG -u DEBUG -u GH_FORCE_TTY \
      gh api --hostname github.com "$@" || api_status=$?
    unset api_token
    return "$api_status"
  else
    env -u GH_DEBUG -u DEBUG -u GH_FORCE_TTY \
      gh api --hostname github.com "$@"
  fi
}

capture_bounded_stdout() {
  local head_pipe="$artifact_dir/.runner-stdout.head.pipe"
  local tail_pipe="$artifact_dir/.runner-stdout.tail.pipe"
  local head_log="$artifact_dir/runner-stdout.head.log"
  local tail_log="$artifact_dir/runner-stdout.tail.log"
  local half_limit=33554432
  local head_pid
  local tail_pid
  local tee_status
  local head_status
  local tail_status

  rm -f -- "$head_pipe" "$tail_pipe"
  if ! mkfifo -m 0600 "$head_pipe" "$tail_pipe"; then
    echo "failed to create private stdout pipes" >&2
    return 1
  fi

  # Keep this FIFO open after the retained prefix so tee can drain arbitrarily noisy output.
  {
    head_capture_status=0
    head -c "$half_limit" > "$head_log" || head_capture_status=$?
    cat >/dev/null
    exit "$head_capture_status"
  } < "$head_pipe" &
  head_pid=$!
  tail -c "$half_limit" < "$tail_pipe" > "$tail_log" &
  tail_pid=$!

  set +e
  # Drain the untrusted stream without rendering terminal-control bytes or creating an unbounded log.
  tee "$head_pipe" "$tail_pipe" >/dev/null
  tee_status=$?
  wait "$head_pid"
  head_status=$?
  wait "$tail_pid"
  tail_status=$?
  rm -f -- "$head_pipe" "$tail_pipe"

  if (( tee_status != 0 || head_status != 0 || tail_status != 0 )); then
    echo "failed to capture bounded runner stdout" >&2
    return 1
  fi
}

delete_runner_id() {
  local runner_id="$1"
  local delete_error_file="$artifact_dir/runner-delete-${runner_id}.error.log"
  local delete_response
  local api_exit
  local http_status
  local attempt
  local retry_after
  local rate_limit_remaining
  local rate_limit_reset
  local retry_delay
  local now

  for attempt in 1 2 3; do
    delete_response="$(github_api \
      --method DELETE \
      --include \
      --silent \
      --header "X-GitHub-Api-Version: $api_version" \
      "repos/$repo/actions/runners/$runner_id" \
      2>"$delete_error_file")"
    api_exit=$?
    http_status="$(printf '%s\n' "$delete_response" | awk '$1 ~ /^HTTP\/[0-9.]+$/ && $2 ~ /^[0-9][0-9][0-9]$/ { code = $2 } END { print code }')"

    case "$http_status" in
      204)
        rm -f -- "$delete_error_file"
        return 0
        ;;
      404)
        # GitHub can conceal an inaccessible repository as 404, so verify access before accepting absence.
        if github_api \
          --silent \
          --header "X-GitHub-Api-Version: $api_version" \
          "repos/$repo/actions/runners?per_page=1" \
          >/dev/null 2>"$delete_error_file"; then
          rm -f -- "$delete_error_file"
          return 0
        fi
        if (( attempt < 3 )); then
          sleep $((attempt * 2))
          continue
        fi
        ;;
      403 | 429)
        retry_after="$(printf '%s\n' "$delete_response" | awk 'tolower($1) == "retry-after:" { gsub(/\r/, "", $2); value = $2 } END { print value }')"
        rate_limit_remaining="$(printf '%s\n' "$delete_response" | awk 'tolower($1) == "x-ratelimit-remaining:" { gsub(/\r/, "", $2); value = $2 } END { print value }')"
        rate_limit_reset="$(printf '%s\n' "$delete_response" | awk 'tolower($1) == "x-ratelimit-reset:" { gsub(/\r/, "", $2); value = $2 } END { print value }')"

        if [[ "$http_status" == 429 || "$retry_after" =~ ^[0-9]+$ || "$rate_limit_remaining" == 0 ]]; then
          retry_delay=$((attempt * 2))
          if [[ "$retry_after" =~ ^[0-9]+$ ]]; then
            retry_delay="$retry_after"
          elif [[ "$rate_limit_reset" =~ ^[0-9]+$ ]]; then
            now="$(date +%s)"
            retry_delay=$((rate_limit_reset - now))
            (( retry_delay > 0 )) || retry_delay=1
          fi

          if (( retry_delay > 60 )); then
            printf 'GitHub rate limit defers runner %s cleanup for %ss; reconciliation is required\n' \
              "$runner_id" "$retry_delay" >&2
            return 1
          fi
          if (( attempt < 3 )); then
            sleep "$retry_delay"
            continue
          fi
        fi
        ;;
      408 | 500 | 502 | 503 | 504 | "")
        if (( attempt < 3 )); then
          sleep $((attempt * 2))
          continue
        fi
        ;;
    esac

    printf 'failed to delete GitHub runner %s (HTTP %s, gh exit %s)\n' \
      "$runner_id" "${http_status:-unknown}" "$api_exit" >&2
    if [[ -s "$delete_error_file" ]]; then
      sed -n '1,3p' "$delete_error_file" >&2
    fi
    return 1
  done
}

find_runner_ids_by_name() {
  local reconcile_error_file="$artifact_dir/runner-reconcile.error.log"
  local runner_ids
  local attempt

  for attempt in 1 2 3; do
    if runner_ids="$(github_api \
      --paginate \
      --header "X-GitHub-Api-Version: $api_version" \
      --jq ".runners[] | select(.name == \"$runner_name\") | .id" \
      "repos/$repo/actions/runners?per_page=100" \
      2>"$reconcile_error_file")"; then
      rm -f -- "$reconcile_error_file"
      if [[ -n "$runner_ids" ]]; then
        printf '%s' "$runner_ids"
        return 0
      fi
      if (( attempt == 3 )); then
        echo "runner creation remains unresolved: no matching registration is visible yet" >&2
        return 1
      fi
    elif (( attempt == 3 )); then
      echo "failed to reconcile the GitHub runner by name" >&2
      if [[ -s "$reconcile_error_file" ]]; then
        sed -n '1,3p' "$reconcile_error_file" >&2
      fi
      return 1
    fi

    sleep $((attempt * 2))
  done
}

delete_runner_registration() {
  local runner_ids=""
  local runner_id
  local delete_failed=0

  if [[ ! -L "$runner_id_file" && -f "$runner_id_file" ]]; then
    IFS= read -r runner_id < "$runner_id_file"
    if [[ "$runner_id" =~ ^[0-9]+$ ]]; then
      runner_ids="$runner_id"
    fi
  fi

  # Reconcile an ambiguous POST or local write failure by the collision-resistant runner name.
  if [[ -z "$runner_ids" ]]; then
    runner_ids="$(find_runner_ids_by_name)" || return 1
  fi

  while IFS= read -r runner_id; do
    [[ -z "$runner_id" ]] && continue
    if [[ ! "$runner_id" =~ ^[0-9]+$ ]]; then
      echo "GitHub returned an invalid runner ID during cleanup" >&2
      delete_failed=1
      continue
    fi
    delete_runner_id "$runner_id" || delete_failed=1
  done <<< "$runner_ids"

  return "$delete_failed"
}

cleanup() {
  local status=$?
  local cleanup_failed=0

  trap - EXIT INT TERM
  set +e

  if (( sandbox_may_exist != 0 )); then
    if ! msb rm -f "$sandbox_name" >/dev/null 2>&1; then
      echo "failed to remove sandbox: $sandbox_name" >&2
      cleanup_failed=1
    fi
  fi
  if (( jit_runner_may_exist != 0 )); then
    delete_runner_registration || cleanup_failed=1
  fi
  rm -f -- "$artifact_dir/.runner-stdout.head.pipe" "$artifact_dir/.runner-stdout.tail.pipe"
  if [[ -n "${jit_api_error_file:-}" && ! -s "$jit_api_error_file" ]]; then
    rm -f -- "$jit_api_error_file"
  fi

  printf 'Runner artifacts: %s\n' "$artifact_dir" >&2

  if (( cleanup_failed != 0 )); then
    printf 'remote or local cleanup requires reconciliation\n' > "$artifact_dir/cleanup-pending"
    echo "cleanup was incomplete; inspect the private artifact directory" >&2
    if (( status == 0 )); then
      status=1
    fi
  else
    rm -f -- "$artifact_dir/cleanup-pending"
  fi
  exit "$status"
}

trap cleanup EXIT
trap 'exit 130' INT
trap 'exit 143' TERM

msb doctor
msb snapshot verify "$snapshot_name"
github_api --silent \
  --header "X-GitHub-Api-Version: $api_version" \
  "repos/$repo/actions/runners?per_page=1" >/dev/null

sandbox_may_exist=1
msb run --detach --name "$sandbox_name" \
  --from-snapshot "$snapshot_name" \
  --cpus 4 --memory 8G \
  --max-duration 2h \
  --net public \
  --security default \
  --label example=github-actions-jit \
  --env HOME=/home/runner \
  --user runner \
  --workdir /opt/actions-runner \
  -- bash -lc 'exec sleep 7200'

set +e
jit_api_error_file="$artifact_dir/jit-api.error.log"
jit_runner_may_exist=1
github_api \
  --method POST \
  --header "X-GitHub-Api-Version: $api_version" \
  --field "name=$runner_name" \
  --field runner_group_id=1 \
  --field "labels[]=self-hosted" \
  --field "labels[]=linux" \
  --field "labels[]=$runner_arch" \
  --field "labels[]=$runner_label" \
  --field work_folder=_work \
  --jq '(.runner.id | tostring), .encoded_jit_config' \
  "repos/$repo/actions/runners/generate-jitconfig" \
  2>"$jit_api_error_file" |
  {
    IFS= read -r generated_runner_id
    if [[ ! "$generated_runner_id" =~ ^[0-9]+$ ]]; then
      echo "GitHub returned an invalid runner ID" >&2
      exit 1
    fi
    if ! printf '%s\n' "$generated_runner_id" > "$runner_id_file"; then
      echo "failed to save the generated runner ID" >&2
      exit 1
    fi
    cat
  } |
  msb exec --stream \
    --user runner \
    --workdir /opt/actions-runner \
    --env RUNNER_MANUALLY_TRAP_SIG=1 \
    --env ACTIONS_RUNNER_PRINT_LOG_TO_STDOUT=1 \
    --timeout 115m \
    --rlimit nproc=512 \
    --rlimit nofile=4096 \
    "$sandbox_name" -- bash -c '
      set -euo pipefail
      IFS= read -r encoded_jit_config
      if [[ -z "$encoded_jit_config" || "$encoded_jit_config" == null ]]; then
        echo "missing encoded JIT configuration" >&2
        exit 1
      fi
      exec ./run.sh --jitconfig "$encoded_jit_config"
    ' 2>&1 |
  capture_bounded_stdout
pipeline_status=("${PIPESTATUS[@]}")
set -e

if (( pipeline_status[0] == 0 )); then
  rm -f -- "$jit_api_error_file"
else
  echo "GitHub JIT configuration request failed; details are in $jit_api_error_file" >&2
fi

runner_status=0
for stage_status in "${pipeline_status[@]}"; do
  if (( stage_status != 0 )); then
    runner_status=$stage_status
    break
  fi
done

exit "$runner_status"
```

## Run one job

<Steps>
  <Step title="Queue the workflow">
    Pass the same label you chose on the host. The run will remain queued until a matching runner connects.

    ```sh
    gh workflow run microsandbox-jit.yml \
      --repo "$repo" \
      --field runner_label="$label"
    ```
  </Step>

  <Step title="Start the temporary runner">
    Run the controller in the same terminal where you set `repo` and `label`:

    ```sh
    /usr/local/sbin/msb-github-jit "$repo" "$label"
    ```

    The command creates a VM, registers the runner, and waits while it claims and executes the queued job. It returns after the runner exits and cleanup finishes. Follow the job from the repository's **Actions** page; the controller deliberately does not render untrusted job output in the host terminal.
  </Step>

  <Step title="Confirm the result">
    The latest run should be complete, and no matching runner should remain registered:

    ```sh
    gh run list --repo "$repo" --workflow microsandbox-jit.yml --limit 1
    gh api --hostname github.com "repos/$repo/actions/runners" \
      --jq ".runners[] | select(any(.labels[]; .name == \"$label\")) | .name"
    ```

    The second command should print nothing. The controller also prints the private host directory containing its bounded diagnostic logs.
  </Step>
</Steps>

Use one controller invocation per worker. The runner accepts one matching job, then the controller deletes the VM and any remaining GitHub registration.

## Security

The default controller creates no host mounts, exposes no host Docker socket, keeps the repository administration token on the host, bounds retained logs, and cleans up on success, failure, or interruption. The job still controls everything inside its VM and has public internet access, so give untrusted workflows no repository or cloud secrets beyond the minimum job permissions they need. See GitHub's [secure use guidance](https://docs.github.com/en/actions/reference/security/secure-use#hardening-for-self-hosted-runners).

## Run it continuously

On a hosted Linux machine with KVM, invoke one controller for each validated `workflow_job` event whose action is `queued`. Set `MSB_GITHUB_TOKEN_COMMAND` to an administrator-owned executable that mints a fresh GitHub App installation token for each API call. At fleet scale, use GitHub's [runner scale-set client or Actions Runner Controller](https://docs.github.com/en/actions/reference/runners/self-hosted-runners#autoscaling).

## Verified

This exact builder and controller ran [GitHub Actions job 91178286410](https://github.com/superradcompany/microsandbox/actions/runs/30624020450/job/91178286410) inside an ARM64 Ubuntu 24.04 microVM, uploaded its artifact, deregistered the runner, and removed the VM. Startup-failure and interruption checks also cleaned up both sides.
