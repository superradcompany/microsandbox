For the default stable installation and your first sandbox, follow the [Quickstart](/getting-started/quickstart).

## Install a release candidate

Installers select the latest stable release by default. To try the newest active release candidate, explicitly select the `rc` channel:

<CodeGroup>
```bash macOS & Linux
curl -fsSL https://install.microsandbox.dev | sh -s -- --channel rc
```

```powershell Windows
$env:MSB_INSTALL_CHANNEL = "rc"
try { irm https://install.microsandbox.dev/windows | iex }
finally { Remove-Item Env:MSB_INSTALL_CHANNEL }
```
</CodeGroup>

## Install an exact version

To pin an exact release, use `--version 0.8.0-rc.1` on Unix or set `$env:MSB_INSTALL_VERSION = "0.8.0-rc.1"` on Windows before invoking the installer. This is an example version; it must have a published release with a bundle for your platform. A downloaded PowerShell script also accepts `./install.ps1 -Channel rc` or `./install.ps1 -Version 0.8.0-rc.1`.

## Selection behavior

Both installers accept `MSB_INSTALL_CHANNEL` and `MSB_INSTALL_VERSION`. Flags override the corresponding environment variable. Do not combine a channel and an exact version. The RC channel selects the highest published `X.Y.Z-rc.N` version, ignores drafts and other prereleases, and excludes candidates at or below a published stable version. If no active candidate exists, or its platform bundle is missing, installation fails without falling back to stable. Exact version selection can still install an older candidate.

## Switching versions

Selection applies to this invocation; it does not subscribe future installs to a channel. Installation uses the usual `MSB_HOME` and command links, so selecting an RC replaces the installed runtime there. Use a separate `MSB_HOME` for disposable testing and invoke its binary by full path when switching between installations. Returning to stable restores the binaries, not any catalog or snapshot changes made while running the candidate.

## Package channels

For npm, use `npm install microsandbox@rc` or pin a published version with `npm install --save-exact microsandbox@0.8.0-rc.1`. Docker candidates use `ghcr.io/superradcompany/microsandbox:rc` and exact version tags. Homebrew and Winget remain stable-only; use the installer to try an RC. SDK CLI shims may prefer an existing configured runtime over their bundled binary, so check the actual runtime version when testing.
