Run agents and workloads locally for as long as you want. When you need more compute, our managed cloud is one CLI command or one SDK context change away. Keep the same sandbox code, switch back whenever you want, and let us manage the cloud infrastructure.

<Note>
Our managed cloud is in private beta. [Request access](https://dashboard.microsandbox.dev/signup).
</Note>

## Connect

Follow [Connect](/cloud/connect) to set up your CLI or SDK and switch between local and cloud execution. You do not need a local runtime or hardware virtualization to use our managed cloud.

The Free plan runs ephemeral sandboxes for up to one hour each and removes them when they stop. Set `ephemeral` at creation as shown in the [quickstart](/getting-started/quickstart), or use `msb run` without `--name`.
