## Fixes

- **Homebrew installs work on macOS.** The v0.7.12 Homebrew install failed because Homebrew could not relocate the bundled `libkrunfw` library. The macOS build now leaves room for Homebrew to rewrite its path, so installs and upgrades complete.

This release contains no runtime or SDK API changes beyond v0.7.12. If you skipped v0.7.12, read its [Before upgrading](/changelog/v0.7.12#before-upgrading) notes first.
