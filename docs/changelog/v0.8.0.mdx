## Prepare your application

v0.8 introduces explicit SDK contexts, usable resource objects from lookups, and fresh asynchronous inspection. Snapshot histories and individual checkpoints have separate resource types. Local and remote distributions let applications install only the native provider they need; full packages remain available.

Follow [Migrating from v0.7 to v0.8](/migrations/v0.8) before upgrading. The detailed [SDK API migration](/migrations/v0.8#sdk-api-migration) and [distribution guide](/migrations/v0.8#sdk-distribution-migration) cover exact calls and package names.

Running sandboxes retain their runtime and guest agent until restarted. Update independently installed runtime pairs and test restart as well as existing connections.

For shipped fixes and features, see the [v0.7 release history](/changelog/v0.7.16).
