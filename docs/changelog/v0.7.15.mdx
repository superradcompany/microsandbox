## New features

**Choose the version you install.** The installers still default to the latest stable release. You can now pin an exact published version, or opt in to the newest release candidate with the `rc` channel:

```bash
# Install an exact version.
curl -fsSL https://install.microsandbox.dev | sh -s -- --version 0.7.15

# Install the newest release candidate.
curl -fsSL https://install.microsandbox.dev | sh -s -- --channel rc
```

On Windows, set `MSB_INSTALL_VERSION` or `MSB_INSTALL_CHANNEL` before running the installer, or pass `-Version` or `-Channel` to a downloaded `install.ps1`. If no active candidate exists, or it has no bundle for your platform, the `rc` channel fails instead of falling back to stable. Release candidates also publish to the npm `rc` tag and the Docker `rc` tag. Homebrew and Winget stay stable-only. [Versions](/getting-started/versions)

**Faster small-file work on mounted host directories.** On macOS and Linux, local sandboxes now keep file descriptors open across file creation, metadata, and extended-attribute operations instead of closing and reopening them. This cuts host work for workloads that touch many small files, especially on network-backed directories. Flush and `fsync` behavior is unchanged. [Volumes](/sandboxes/volumes)

## Fixes

- New boots use guest Linux 6.12.117. On Windows x64, the guest kernel restores container networking, policy routing, and POSIX message queues.

## Before upgrading
