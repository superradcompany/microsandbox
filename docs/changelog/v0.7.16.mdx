## Highlights

Services are available through the CLI and SDKs. See [Services](/sandboxes/services) for supported operations.

## Fixes

The network stack revalidates SNI DNS bindings on reconnect. SDKs decode every cloud sandbox status, cloud modifications use canonical endpoints, and guest bulk-cleanup bursts no longer stop the guest. The release also updates libkrun and firmware and repairs Rust toolchain checks.
